# V9968 BASIC 命令リファレンス

[READMEへ戻る](../README.md)

`_` はMSX BASICの `CALL` の省略形です。例えば `_SCREEN(5)` は `CALL SCREEN(5)` と同じ意味です。
以下の構文中の `[ ... ]` は省略可能な部分を表し、実際には角括弧を書きません。数値にはBASICの式・変数を使えます。
拡張描画は必要な状態を自動で有効にしません。最初に `_SCREEN(5)` などで初期化してください。

## 画面・パレット

| 書式 | 内容 |
|---|---|
| `_V9968` | V9968を検出し、高速コマンド・拡張パレット・拡張VRAMなどを有効化 |
| `_SCREEN(M[,S,K,B,P,I,H,V])` | 画面の初期化、または指定した項目だけの更新。Mは0・5・6・7・8 |
| `_SET PAGE(D,A)` | 表示ページDと描画ページAを指定 |
| `_COLOR=(N,R,G,B)` | パレット番号N=0～255、RGB各0～31 |
| `_PATTERN ON(P)` / `_PATTERN OFF` | 4bpp素材描画の有効化／解除。素材ページP=0～7 |
| `_VDP(N)=X` | 追加VDPレジスタの書き込み。N=48～59、X=0～255 |

`_SCREEN` の第1～6引数は標準 `SCREEN` と同じ位置です。M=画面、S=スプライトサイズ、K=キークリック、B=ボーレート、P=プリンタ指定、I=インターレース指定です。
I=0～3は標準と同じ意味、**I=4** はフラットインターレースです。
**H=0** は通常、**1** は優先順位シャッフル、**2** は水平16枚、**3** は両方。
**V=0** はスプライトが縦スクロールに追従、**1** はスクロールから位置を独立させます。

Sは0=8×8、1=8×8の2倍、2=16×16、3=16×16の2倍です。モード3の大きさはSではなく `SIZE(W,H)` で指定します。
Kは0=OFF・1=ON、Bは1=1200・2=2400 baud、Pは0=MSX・1=非MSXプリンタです。K・Pは標準と同じく0～255を受理します。カセット・プリンタの実際の機能は機種に依存します。

```basic
_SCREEN(7,,,,,4)
_SCREEN(,,,,,,3)
_SCREEN(,,,,,,,1)
```

画面番号を省略すると指定項目だけを更新します。画面番号付きではフォント・スプライト設定などを初期化します。
画面番号付きでH・Vを省略すると両方0になり、画面番号を省略した部分更新では未指定の値を保持します。空の呼び出しや末尾のカンマは使えません。
SCREEN 0はテキスト画面に戻って拡張モードを解除します。SCREEN 1～4でモード3を使う場合は、標準 `SCREEN` と `_V9968` を併用します。
サイズ変更は標準SCREENを介してスプライトテーブルを初期化するため、有効なフォント／モード3がある状態でのサイズだけの変更は拒否します。
シャッフルだけでは1ラインの表示枚数は増えません。水平16枚指定は従来モード1・2向けで、モード3はこの指定にかかわらず1ライン最大16枚です。

| 画面 | X座標 | 色番号 | 通常ページ | FILページ |
|---|---|---|---|---|
| SCREEN 5 | 0～255 | 0～15 | 0～7 | 0～3 |
| SCREEN 6 | 0～511 | 0～3 | 0～7 | 0～3 |
| SCREEN 7 | 0～511 | 0～15 | 0～3 | 0～1 |
| SCREEN 8 | 0～255 | 0～255 | 0～3 | 0～1 |

描画Y座標は通常0～255、FILでは0～511。通常の表示高は212行、FILは424行です。
ページ表は描画・COPYの指定範囲であり、全ページの直接表示を保証するものではありません。[表示上の制限](../README.md#対応範囲と制限)も確認してください。

## 描画・COPY

| 書式 | 内容 |
|---|---|
| `_CLS` / `_CLS(C)` | 描画ページを背景色／指定色で消去 |
| `_PSET(X,Y)[,C]` | 点を描画 |
| `_LINE (X1,Y1)-(X2,Y2)[,C[,BまたはBF]]` | 線、矩形枠B、塗りつぶしBF。B／BF指定時は色も必要 |
| `_CIRCLE [STEP](X,Y),R[,C,S,E,A]` | 円・楕円・円弧。S・Eは開始／終了角（ラジアン）、Aは縦横比 |
| `_COPY (X1,Y1)-(X2,Y2),SP TO (X,Y),DP[,L,AN,SC]` | VRAMの矩形コピー。L=論理演算、AN=角度（度）、SC=倍率 |
| `_COPY (X1,Y1)-(X2,Y2),SP TO (X3,Y3)-(X4,Y4),DP[,L,AN,SC]` | 転送先矩形も指定するCOPY |
| `_COPY (X1,Y1)-(X2,Y2),SP TO A%` | DIM済み数値配列へ画像を保存 |
| `_COPY(A%)[,D] TO (X,Y),DP[,L]` | 配列から画像を復元。D=0～3で転送方向を指定 |
| `_WAIT VDP` | VDPコマンドの完了待ち |
| `_WAIT VBLANK` | 次の垂直帰線期間の開始待ち |

COPYのL・AN・SCは固定位置で、それぞれ省略時に **PSET・0度・1倍** へ戻ります。前回の値は引き継ぎません。
Lは `PSET`、`PRESET`、`AND`、`OR`、`XOR` と、それぞれの先頭にTを付けた10種類です。T付きは転送元の色0を書き込みません。
角度・倍率は普通の数値引数です。`ROTATE(...)`・`SCALE(...)` という旧書式は使いません。

裏ページの画像を30度回転・0.75倍でコピーする例：

```basic
10 _SCREEN(5)
20 _COLOR=(3,0,31,24)
30 _SET PAGE(0,7):_CLS(0)
40 _LINE (16,16)-(79,79),3,BF
50 _LINE (24,24)-(71,71),15,B
60 _SET PAGE(0,0):_CLS(0)
70 _COPY (0,0)-(95,95),7 TO (80,56)-(175,151),0,,30,.75
80 IF INKEY$="" THEN 80
90 _SCREEN(0)
```

通常の同一ページCOPYは領域の重なりに対応します。回転・拡大縮小などを伴う同一ページCOPYは、転送元と転送先が重ならない場合だけ使用できます。
配列COPYは整数・単精度・倍精度の数値配列に対応し、文字列配列や添字指定は使えません。十分な容量を `DIM` で確保してください。画像形式は先頭4バイトの幅・高さと、続く画素データです。配列からの回転・拡縮は非対応で、一度VRAMに転送してから行います。

配列の必要容量は `4+INT((幅*高さ*ビット数+7)/8)` バイトです。SCREEN 5・7とPATTERNは4bpp、SCREEN 6は2bpp、SCREEN 8は8bppで、保存時と同じ画素形式で復元します。整数配列は1要素2バイトなので、32×32の4bpp画像は `DIM A%(257)`（258要素、516バイト）に入ります。画像バッファとして使っている間は、要素を通常の数値計算に使用しないでください。
方向Dは省略／0=右下、1=左下、2=右上、3=左上です。指定座標が最初の画素になるため、幅32の画像を左右反転してX=96～127に置くなら、`_COPY(A%),1 TO(127,Y),DP` とします。

`_CIRCLE` の半径は0～32767、中心座標は符号付き16ビットです。画面外はクリップします。負の開始／終了角は中心線も描く指定で、既定の縦横比は画面に合わせます。

<a id="copy-completion"></a>

### COPYの完了待ち

通常・回転・拡大縮小・配列COPYは、前のVDP処理を待ってから転送を開始し、今回の転送が完了してからBASICへ戻ります。
**COPY直後の `_WAIT VDP` は不要**です。コマンド完了待ちと垂直同期は別であり、COPYが毎回VBLANKを待つわけではありません。

### PATTERN中の描画

`_PATTERN ON(P)` 中は、拡張PSET・LINE・CIRCLE・CLS・COPYをSCREEN 5形式（256×256、16色、32KBページ）として扱います。
COPYは命令に書いた転送元・転送先ページを使い、それ以外の対象描画はPへ書き込みます。表示形式の変換ではありません。
標準描画命令・GRP・FONT・SPRITE・SET PAGEの意味は変わりません。繰り返しのONは最後の有効なページを採用し、OFFは解除済みでも使えます。

## スプライトモード3

| 書式 | 内容 |
|---|---|
| `_SPRITE(3)` / `_SPRITE(0)` | モード3の初期化／解除 |
| `_PUT SPRITE(N,X,Y)[,C,P,オプション...]` | スプライトN=0～63の配置。C=パレットセット0～15、P=絵柄0～2047 |
| `_SPRITE ON` / `_SPRITE OFF` | 全体の表示／非表示 |
| `_SPRITE OFF(N)` | 1枚を非表示にする |
| `_SPRITE CLEAR` | 全64枚の属性を初期化して非表示にする。絵柄は消さない |

`_PUT SPRITE` のN・X・Yは必須です。座標は各-512～511。C・P・オプションは省略すると以前の値を保持します。

| オプション | 内容 |
|---|---|
| `SIZE(W,H)` | 表示幅・高さを各1～256ドットに設定 |
| `PATTERN(H)` | 元の絵柄の高さを16・32・64・128から選択。元の幅は16ドット |
| `FLIP(F)` | 0=なし、1=左右、2=上下、3=両方 |
| `TRANS(T)` | 透明度0・25・50・75%。0が不透明 |

```basic
_PUT SPRITE(0,80,60),0,1792,SIZE(32,32),TRANS(50)
_PUT SPRITE(0,100,60)
_PUT SPRITE(0,100,60),,,FLIP(1)
```

絵柄はSCREEN 5形式のVRAM画像を参照します。Pは `素材ページ*256 + (絵柄Y/16)*16 + 絵柄X/16` で、絵柄位置は16ドット単位です。1792は素材ページ7の(0,0)です。
色0は透明、C=1では元画像の色1～15にパレット17～31を使います。半透明は背景との合成です。
絵柄の準備には `_PATTERN ON(7)` などを使用でき、座標更新のたびに絵柄やサイズを指定し直す必要はありません。

## フォント・GRP出力

| 書式 | 内容 |
|---|---|
| `_FONT(0)` | 標準のGRP文字描画へ戻る |
| `_FONT(1)` / `_FONT(2)` | BIOSの8×8フォント／太字をVRAMへ読み込む |
| `_FONT$(C)=S$` | 文字コードC=0～255の字形を8バイトの文字列で定義 |

非FILのSCREEN 5で使用します。文字列を描く命令は追加せず、標準の `OPEN "GRP:"`、`PSET`／`PRESET`、`PRINT #` を使います。
色は標準 `COLOR` で指定します。文字位置だけを設定する場合は、点を描くPSETではなく、背景色を置くPRESETを使用できます。

```basic
10 _SCREEN(5):_FONT(2):COLOR 15,0,0:_CLS(0)
20 OPEN "GRP:" AS #1
30 PRESET(16,16):PRINT #1,"HELLO V9968";
40 IF INKEY$="" THEN 40
50 CLOSE #1:_FONT(0):_SCREEN(0)
```

<a id="font-completion"></a>

有効な拡張フォントでの文字出力は、LFMMによる各字形の描画完了を待ち、背景色レジスタを復元してからBASICへ戻ります。`PRINT #` の後へ `_WAIT VDP` を付ける必要はありません。

## 予約領域・エラー

フォント有効時はVRAMの37600h～37DFFh（2KB）、モード3有効時は37E00h～37FFFh（512バイト）を予約します。
有効化時に以前の内容を上書きします。拡張描画は使用中の予約領域を保護しますが、標準命令やVPOKE・直接OUTによる書き込みまでは保護しません。

非対応画面・不正な範囲・必要な拡張状態の未設定は `Illegal function call`（ERR=5）、構文不正は `Syntax error`（ERR=2）です。
BASIC自身の型・式評価・ファイル処理のエラーは、そのままBASICへ返します。

<a id="vdp-register-plan"></a>

### 追加レジスタ

`_VDP(N)=X` はBASICの番号付けに合わせ、N=48～59でR#47～58を書き込みます。ECOMが必要です。
前のコマンド完了を待ちますが、この命令だけでは描画を開始しません。既存レジスタは標準 `VDP` を使います。
読み出し関数はありません。標準VDPから直接開始した描画には、拡張ROMのVRAM予約保護は適用されません。
