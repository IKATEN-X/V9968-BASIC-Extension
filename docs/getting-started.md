# 導入・ビルド・デモの起動

[READMEへ戻る](../README.md)

以下はWindowsでソースからビルドする手順です。コマンドはリポジトリのルートフォルダーで、PowerShell 7から実行してください。
`pwsh` と `node` にPATHが通っている必要があります。

## エミュレータの準備

対応対象は、V9968を内蔵VDPとして使用する機種構成です。外付けカートリッジを追加する `HRA_V9968` 拡張は対応対象ではありません。

openMSX 21.0のデータファイルと、手元のMSXシステムROMを用意します。
次のパスは例なので、自分の環境に合わせて変更してください。

```powershell
.\tools\setup.ps1 -OpenMsx 'C:\Program Files\openMSX' `
    -BiosDirectory 'C:\MSX\roms' `
    -SystemRoms 'C:\MSX\roms'
```

| 引数 | 指定するもの |
|---|---|
| `-OpenMsx` | `openmsx.exe` と `share/` を含む既存のopenMSXインストールフォルダー |
| `-BiosDirectory` | `MSX2P.rom` と `MSX2PEXT.rom` を直接置いたフォルダー |
| `-SystemRoms` | FS-A1STの機種定義が参照するシステムROMのフォルダー。サブフォルダーも検索 |

MSX2+の2ファイルは最小Z80構成の準備に使用します。**既定のディスク付きデモにはFS-A1STのROMも必要**です。機種定義と一致するファイル名で用意してください。
FS-A1STを準備できず最小構成だけを使用する場合は、後述の単独起動を選びます。

セットアップは既存のopenMSXデータを `.local/` へコピーし、検証対象のV9968バイナリ `c620b69`（2026-09-23）をダウンロードしてハッシュを確認します。
既存のopenMSXインストールは変更しません。BIOSのダウンロードも行いません。
検証対象を固定しているため、V9968版openMSXの別ビルドへの差し替えは、この手順での動作確認範囲外です。

機種定義のVDPは、新レジスタ定義を使う `V9968` にします。`V9968_OLD` は使用しません。
旧環境から更新する場合は、**エミュレータ本体と拡張ROMの両方を更新**してください。
`run.bat` は `.local/openmsx/openmsx.exe` を使用します。Catapultなどから別のインストール先を起動する場合、その `openmsx.exe` は別途更新が必要です。

## ビルドと起動

z88dkのインストール先を指定してビルドします。

```powershell
.\build.ps1 -Z88dk 'C:\tools\z88dk'
.\run.bat -NoBuild
```

出力は `dist/v9968-basic.rom`（16KB）です。BASICのCALL拡張ROMであり、自動実行ゲームROMではありません。
`run.bat` はFS-A1ST(V9968)を起動し、仮想フロッピーの `AUTOEXEC.BAS` からデモメニューを開きます。

ビルドスクリプトの既定のz88dkパスは `D:\z88dk` です。そこにインストールしている場合は `run.bat` だけでビルド・起動できます。
別の場所にインストールした場合は、上のように明示ビルドと `-NoBuild` を組み合わせてください。`run.bat` 自体には `-Z88dk` 引数はありません。

## デモメニュー

| キー | デモ |
|---|---|
| 1 | 画像・パレット・フォント・文字列のファイル読み込み |
| 2 | フォント描画 |
| 3 | 拡大縮小・半透明スプライト |
| 4 | 回転・拡大縮小COPY |
| 5 | SCREEN 8の256色パレット |
| 6 | スプライト優先順位シャッフル |
| 7 | 水平16枚表示 |
| 8 | 32枚のスプライト波形 |
| 9 | シューティング「SKYLINE PATROL」 |
| F | フラットインターレース |
| L | 論理COPY |
| C | 円・楕円・円弧 |
| W | 操作できる3Dワイヤーフレーム |
| R | ランダムに曲がる道路と自車の走行試作 |
| 0 / Esc | BASICへ戻る |

漢字デモのCtrl＋STOP（BREAK）は、メニューへ戻らずBASIC本来の停止になります。プログラムと変数を残したまま確認・編集できます。メニューへ戻る操作はEscです。

各デモからはEscでメニューへ戻れます。主な操作は以下のとおりです。

- 漢字フォント（K）：Spaceで日本語を100回描画、Bで標準漢字BASICとの比較、Rで初期画面へ戻ります。比較途中の標準描画表示中もRで戻れます。漢字ROMが必要で、比較には漢字BASICも必要です。`run.bat -NoBuild -Entry KANJI.BAS` で直接起動できます。

- スプライト比較（6・7・8）：1／2でモード選択、Sでシャッフル。7・8はTで水平16枚表示を切り替えます。
- 波形（8）：Spaceで停止／再開。停止中も表示設定を変更できます。
- シューティング（9）：Spaceで開始・発射、カーソルキーで移動、Pで一時停止。
- 回転（4）：Spaceで停止／再開、+／-で回転速度を変更。
- 論理COPY（L）：Pで自動実行を停止／再開、Spaceで次の絵柄を転送。
- ワイヤーフレーム（W）：矢印キーで2軸回転、1／2／3で立方体・八面体・二十面体を選択、+／-で拡大縮小、Spaceで自動回転の切り替え、Rで初期角度・倍率に戻します。矢印を操作すると手動回転へ戻ります。
- 道路走行（R）：左右キーまたはジョイスティック1で自車を左右に動かします。前進は自動で、左右に曲がる道路をランダムに生成します。現在は道路と自車だけの試作で、敵車・衝突判定・加減速・スコアはありません。

道路走行のソースは [ROAD.BAS](../demo/ROAD.BAS) です。SCREEN 5の縦スクロールと、見えない領域への16ドット高の帯のCOPYを組み合わせています。自車はスプライトモード3で表示し、SVNSで背景スクロールの影響を切り離しています。1回の更新で道路・自車とも4ドット移動し、ループ末尾の `_WAIT VBLANK` で表示周期に合わせます。実行時の三角関数計算はありません。

ワイヤーフレームは、選択中の図形と倍率について、全姿勢の画面座標と線の色をBASICの配列に事前計算します。起動時・図形変更時・倍率変更時には準備画面が入り、回転中は計算済みデータを参照して描画します。準備中もEscで終了できます。
角度は立方体・八面体が横15度／縦30度刻み、二十面体が横・縦とも30度刻みです。自動回転は横・縦を交互に1段階ずつ進めます。矢印キーは押した直後に1段階、長押し中は最短約0.33秒間隔で進みます。二十面体への変更時は横角度を30度単位に切り下げます。座標・色のテーブルは最大16,128バイトで、BASICの通常の`DIM`／`ERASE`を使って管理しています。

特定のデモから始める場合：

```powershell
.\run.bat -NoBuild -Entry WAVE.BAS
```

## BASICを編集する

デモの編集元は `demo/` と `demo/disk/` です。起動ごとに画像素材などと一緒に `build/disks/demo-XXXXXX/` へコピーし、読み取り専用の仮想ディスクとして使用します。

編集用の `.BAS`・`.TXT`・`.DAT` はUTF-8で保存してください。日本語を直接記述でき、起動時にShift-JIS（CP932）へ変換します。ASCIIの既存ファイルもそのまま使えます。画像などのバイナリは変換しません。
Shift-JISに変換できない文字はエラーになり、BASICの1行は変換後254バイトまでです。変換可能でも、表示には対象の漢字ROMやフォントに字形が必要です。

`-Program` による単独起動も同じ変換を行い、`build/programs/` の一時コピーから入力します。変換には既存のPowerShell 7と.NET標準の文字コード処理を使用し、ROM側の処理は変更しません。

`-NoBuild` でもファイルセットは再生成するので、BASICの変更は次の起動で反映されます。MSX側からのSAVEはできません。

ディスクを必要としないプログラムは、単独で起動できます。

```powershell
.\run.ps1 -NoBuild -Program demo/ORBIT.BAS
.\run.ps1 -NoBuild -Machine V9968_Basic -Program demo/ORBIT.BAS
```

単独起動はBASICをキーボード入力で流し込む方式です。最小Z80構成の `V9968_Basic` にはディスクドライブがないため、ディスクメニューや外部画像を読むシューティング・道路走行は使用できません。

## 手動起動時の注意

Catapultなどから手動で起動する場合も、検証対象のV9968バイナリとV9968を指定した機種定義が必要です。**機種のファイル名を変えるだけではVDPは変わりません。**
ROMは `dist/v9968-basic.rom`、配置指定は `Normal`（4000h）を使います。

仮想ディスク用のファイルセットだけを生成するには、次を実行します。

```powershell
node tools/demo-disk.mjs
```

出力JSONの `directory` がマウントするフォルダーです。openMSXのAドライブへ読み取り専用で設定してください。
起動スクリプトと別のopenMSXを使う場合は、そちらのバイナリ・機種定義・ROM検索先も確認します。

メニュー前に `Illegal function call in 10` が出る場合は、まずVDPがV9958のままになっていないか確認してください。
機種設定を変更した場合は再起動が必要です。読み込み済みのBASICも、ホスト側のファイル編集だけでは置き換わりません。
